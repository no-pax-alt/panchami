# 2D Graphics Editor in C

## Introduction

2D Graphics Editor is a menu-driven graphics application developed in C that allows users to create and manage simple drawings using an ASCII-based canvas. The editor supports drawing shapes such as rectangles, circles, lines, and triangles, along with features to add, delete, modify, and move objects. It also includes useful functionality such as an object inspector, statistics dashboard, undo/redo, shape templates, and saving and loading drawings. The project was built to explore graphics concepts, data handling, and structured programming in C.
